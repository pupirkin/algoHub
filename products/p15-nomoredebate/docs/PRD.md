# P15 NoMoreDebate — PRD

## Проблема
Групповой выбор из нескольких вариантов затягивается и оставляет недовольных; простое голосование «за один
вариант» не учитывает компромиссы.

## Ключевой сценарий (acceptance) — ARCHITECTURE_PLAN §7
1. Организатор создаёт комнату: вопрос, 2–10 вариантов, метод (по умолчанию Кондорсе → Борда), необязательный
   дедлайн, лимит участников (2–50, по умолчанию 30) → получает ссылку для участников и свою ссылку организатора.
2. 2–30 участников открывают ссылку без регистрации, вводят имя и упорядочивают варианты (перетаскиванием или
   кнопками ↑↓); голос можно менять, пока комната открыта.
3. Организатор видит, кто проголосовал (но не как), и закрывает голосование — или наступает дедлайн.
4. Все видят победителя и объяснение «почему», включая ничью: её не прячем, показываем все варианты
   с равным результатом и детерминированный жребий (по id комнаты).

## Методы
| Метод | Когда | Объяснение |
|---|---|---|
| `condorcet_borda` (по умолчанию) | Вариант, выигрывающий все дуэли, побеждает; иначе — Борда | дуэли, баллы |
| `borda` | Баллы за места | баллы |
| `irv` | «Как на выборах»: выбывает последний по первым местам | раунды |
| `minimax_regret` | Минимизируем худшее место, на которое вариант попадает у кого-либо | таблица «сожалений» |

Неполные ранжирования допустимы: невыставленные варианты делят последнее место.

## Нецели v1
Аккаунты, чат, комментарии, реальное время (только опрос каждые 3 с), push, интеграции с мессенджерами,
более 50 участников, анонимность от организатора на уровне имён (организатор видит, кто проголосовал).

## Приватность
Публичное состояние комнаты не содержит токенов, хешей, имён и бюллетеней. Индивидуальные бюллетени не
показываются никому, кроме автора, — ни до, ни после закрытия; результат содержит только агрегаты.
В комнатах из 2–3 человек агрегаты могут позволить догадаться о голосах — это свойство любого подсчёта,
указано в UI-подсказке к результату. Хранение: 30 дней после закрытия (или после создания, если комнату
не закрыли), организатор может удалить комнату раньше.
