# P15 NoMoreDebate

Голосование, которое заканчивает спор за минуты. Профиль: **ROOM** (общее состояние на сервере, расчёт в Python).

## Проблема
Компания из 3–30 человек выбирает ресторан, фильм, время встречи — и обсуждение в чате идёт часами: громкие
перекрикивают тихих, голосование «за один вариант» дробит голоса, ничьи решаются тем, кто дольше спорит.

## Персона
Организатор небольшой группы (друзья, коллеги, семья), который хочет быстро получить решение, с которым никто
не будет спорить, потому что видно, *почему* выбран именно этот вариант.

## Ценность
- без регистрации: ссылка на комнату → имя → упорядочить варианты;
- ранжирование вместо «одного голоса»: учитываются вторые и третьи предпочтения;
- объяснение результата: дуэли «кто кого», баллы, раунды, честно показанная ничья и детерминированный жребий.

## Альтернативы
Опросы в мессенджерах (один голос, без объяснения), Doodle (время, не ранжирование), Google Forms (нет
расчёта), специализированные сервисы ranked-choice (англоязычные, с регистрацией).
