# P15 NoMoreDebate — решения

Формат: дата · решение · причина · как откатить.

- 2026-11-13 · Метод по умолчанию `condorcet_borda` (Кондорсе, иначе Борда) · ARCHITECTURE_PLAN §7: «победитель
  по Кондорсе объявляется, Борда — основной метод»; метод монотонен (property-тест) · сменить default в
  `schemas.CreateRoomRequest`.
- 2026-11-13 · Ничья не прячется: `outcome=tie`, все равные варианты + отдельный `tiebreak_option_id` по
  `sha256(room_id:i)` · честность результата и детерминизм; жребий не зависит от бюллетеней · —
- 2026-11-13 · Неполные бюллетени: невыставленные делят последнее место, Борда — средним баллом (удвоенные целые)
  · ARCHITECTURE_PLAN §7; целые числа исключают ошибки округления · —
- 2026-11-13 · Id варианта = его позиция в комнате (0..9), а не глобальный bigint · проще контракт и бюллетень,
  нет утечки счётчика · новая миграция + v2 API.
- 2026-11-13 · Нет поля `title` у комнаты (только `question`) · в UI это одно и то же; меньше полей · добавить
  nullable колонку.
- 2026-11-13 · API вместо `share_url` отдаёт `share_path` и `organizer_path`; токен организатора — во фрагменте
  `#t=` · API не знает публичный адрес портала; фрагмент не уходит на сервер, в логи и Referer · —
- 2026-11-13 · Добавлены `GET /rooms/{id}/participants` (организатор) и `GET /rooms/{id}/ballot` (участник) сверх
  списка §7 · экран организатора «кто проголосовал» и восстановление своего голоса · удалить эндпоинты (v2).
- 2026-11-13 · Дедлайн задаётся как `deadline_minutes` (5 мин … 7 дней) от момента создания · не зависит от часов и
  часового пояса клиента · —
- 2026-11-13 · Дедлайн закрывает комнату лениво (первым запросом после) · нет worker до P31 · фоновое закрытие в
  worker.
- 2026-11-13 · Нет токена → 401 до поиска комнаты · schemathesis (ST203): отсутствие аутентификации должно давать
  401 независимо от id · —
- 2026-11-13 · Пример `three_friends_pizza_tie` из TESTING_STRATEGY §2.3 даёт не ничью, а победу Sushi по Кондорсе
  (2:1 в обеих дуэлях) · проверено oracle; сценарий `sushi_condorcet_winner`, ничья — `three_friends_pizza_cycle` ·
  поправить пример в стратегии в фазе 2.5.
