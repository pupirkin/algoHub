# P15 NoMoreDebate — валидация

## Измеримая гипотеза (ARCHITECTURE_PLAN §7)
**≥ 30 % созданных комнат доходят до закрытия с ≥ 3 участниками** (за первые 4 недели после `LIVE`,
минимум 50 созданных комнат для вывода).

## Как измеряем
- Источник — собственная БД (`p15.rooms`, `p15.results`, `p15.participants`), без персональных данных:
  `closed rooms with participant_count ≥ 3 / created rooms` по неделям. Запрос — в `STATUS.md` при переходе в
  `VALIDATING`.
- События портала в Umami (`product_view`, `scenario_completed`) — когда Umami будет поднят (BUILD_STATE:
  отложено).

## Критерии решения
| Результат | Решение |
|---|---|
| ≥ 30 % | продукт подтверждён, развиваем (SSE, шаблоны вопросов) |
| 15–30 % | интервью 5 организаторов: где бросают (вступление? ранжирование?) |
| < 15 % | пересмотреть формат (быстрый опрос без ранжирования?) или заморозить |

## Статус
Не начата: продукт не задеплоен (хостинг отложен, DEVOPS §4).
